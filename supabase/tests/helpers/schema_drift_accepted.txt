# Les divergences ACCEPTÉES entre la production et un rejeu.
#
# `genre|identité|empreinte_production|empreinte_rejeu  # raison`
#
# ⚠ PAR IDENTITÉ ET PAR EMPREINTE, JAMAIS PAR NOMBRE.
#
# « quarante-sept sont attendues » serait un angle mort : la quarante-huitième
# rougirait, mais l'une des quarante-sept pourrait changer de contenu sans que
# rien ne bouge. Une exception qui ne sait pas ce qu'elle exempte n'exempte pas,
# elle aveugle.
#
# Chaque ligne nomme LE TRIPLET. Si la production change, si le rejeu change, ou
# si l'objet disparaît, le triplet ne correspond plus, la divergence redevient
# comptée, et la CI rougit. C'est le comportement qu'on veut : ces lignes disent
# « cet écart-là, celui que nous avons lu », pas « des écarts sur ces objets ».
#
# ── CE QUI EST ACCEPTÉ, ET SUR QUELLE PREUVE ────────────────────────────
#
# Quarante-sept définitions brutes de fonction, toutes du même écart et toutes
# dans le même sens : LA PRODUCTION EST LE CÔTÉ APPAUVRI. Ce qui les a
# appliquées a retiré les commentaires en chemin ; le dépôt est le côté long,
# sur les quarante-sept, sans exception.
#
# Le classement n'est PAS le regex de schema_fingerprint.sql, dont l'en-tête dit
# lui-même qu'il est faux dans le sens qui fait paraître égales deux définitions
# différentes. Il vient de `scripts/sql_tokens.py`, un vrai lexer PostgreSQL
# dont seize sondes couvrent les trois cas que le regex rate. Verdicts, trois
# permis et pas de quatrième : 0 identique, 47 écarts de commentaire prouvés,
# 0 comportement différent. Le détail est dans
# supabase/tests/helpers/function_drift_2026-09-17.md.
#
# Trente-huit dataient déjà de l'empreinte du 12 septembre. Trois sont arrivées
# avec la récupération des onze. Six sont arrivées le 17 septembre quand le
# dépôt a repris la version LONGUE des onze migrations (celle de
# claude/foundation-lot3-wiring) : ces six fonctions y sont redéfinies, donc le
# rejeu les produit désormais commentées alors que la production porte l'extrait.
#
# ⚠ CE FICHIER NE SE RÉGÉNÈRE PAS EN MASSE. Y ajouter une ligne veut dire :
# quelqu'un a lu la divergence, l'a passée au lexer, et écrit pourquoi elle est
# acceptable. Le régénérer d'un coup après un changement rouge reviendrait à
# supprimer la CI en la gardant verte.
